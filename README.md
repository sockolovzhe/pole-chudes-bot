# 🎰 Телеграм-бот "Поле чудес"

Телеграм-бот для игры "Поле чудес" в групповых чатах.

## 🚀 Установка и запуск

### 1. Получите токен бота

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота

### 2. Установите зависимости

```bash
npm install
```

### 3. Настройте переменные окружения

Создайте файл `.env`:

```
BOT_TOKEN=ваш_токен_бота
```

### 4. Запустите бота

```bash
npm start
```

## 📋 Команды бота

### Команды для всех:

- `/start` - Показать справку с кнопками быстрого доступа
- `/try <буква>` - Угадать букву (например: `/try А`)
- `/guess <слово>` - Угадать слово целиком или одно слово из фразы (например: `/guess ПРИМЕР`)
- `/status` - Показать текущее состояние игры

### Команды для ведущего:

- `/newgame` - Начать новую игру (делает вас ведущим)
- `/word <слово>` - Загадать слово (например: `/word ПРИМЕР`)
- `/end` - Завершить текущую игру и показать результаты

### Интерактивные кнопки:

При команде `/start`, `/newgame` и `/word` появляются кнопки для быстрого доступа:
- **🎮 Новая игра** - начать новую игру
- **👥 Присоединиться** - присоединиться к текущей игре
- **📊 Статус** - показать статус игры
- **❓ Помощь** - показать полный список команд

## 🎮 Как играть

1. **Ведущий** запускает игру командой `/newgame` (или нажимает кнопку)
2. **Ведущий** загадывает слово командой `/word ПРИМЕР` (ведущий не участвует в игре)
3. **Участники** присоединяются командой `/join` или нажимают кнопку **👥 Присоединиться**
4. **Игроки** предлагают буквы командой `/try А` или просто вводят букву (если отключено требование команды)
5. **Первый участник**, который предложит букву, начинает игру
6. **При правильном ответе** (буква или слово) - игрок продолжает ходить
7. **При повторной попытке буквы** - ход не передаётся, можно попробовать другую букву
8. **При ошибке** (новая неверная буква) - ход переходит следующему игроку
9. Игрок может передать ход вручную командой `/next`
10. Угаданные буквы автоматически открываются
11. Игра завершается, когда все буквы угаданы

## ✨ Особенности

- ✅ Поддержка русского и английского алфавитов
- ✅ **Нормализация букв**: Й = И, Ё = Е, Ъ = Ь (считаются эквивалентными при угадывании)
- ✅ Поддержка пробелов в словах (фразы)
- ✅ Очередь игроков с автоматической ротацией
- ✅ Интерактивные кнопки для быстрого доступа
- ✅ Защита от повторных попыток угадать одну букву (ход не передаётся)
- ✅ Список неугаданных букв (отображается в команде `/status`)
- 🎯 **Система очков при /try**: за каждую угаданную букву начисляются случайные очки (100-1000, кратно 100), умноженные на количество вхождений буквы в слове. **Без бонуса**
- 🎁 **Угадывание слова через /guess**: позволяет угадать слово целиком или одно слово из фразы и получить очки за неугаданные буквы + **бонус 1/3** всегда начисляется
- 🏆 **Таблица лидеров** - отображение очков всех игроков в команде `/status`
- 📊 **Детальная статистика** - после завершения игры показывается подробный расчёт очков для каждой буквы

## 🔧 Технологии

- Node.js
- Telegraf (библиотека для Telegram Bot API)
- dotenv (для управления переменными окружения)

Ведущий: /newgame

Игрок 1: /try З (неверно)
→ Бот: ❌ Буквы "З" нет в слове.
   📝 Слово: ПР██ЕР
   🎲 Следующий ход: @Игрок2

Игрок 2: /try И
→ Бот: ✅ Буква "И" есть в слове!
   💰 Вы получили 400 очков!
   (Всего у вас: 400)
   📝 Слово: ПРИ█ЕР
   🎲 Ваш ход продолжается!

Игрок 2: /try М
→ Бот: 🎉 Поздравляем! Игрок @Игрок2 угадал последнюю букву!
   💰 Вы получили 600 очков!
   (Всего у вас: 1000)

   "П": 500 очков

   🏆 Финальная таблица очков:
   🥇 @Игрок1: 1100 очков

### Пример 2: угадывание слова целиком

```
Ведущий: /word ТЕСТ

   💰 Вы получили 1000 очков!
   📝 Слово: Т██Т

Игрок 1: /guess ТЕСТ
→ Бот: 🎉 Правильно! Слово "ТЕСТ" угадано!
   💰 Вы получили 1050 очков!
   (Базовые очки за новые буквы: 700 + бонус: 350)
   Всего у вас: 2050 очков
   
   📊 Детальная статистика очков:
   "Т": 500 очков × 2 вхождений = 1000 очков (уже была угадана)
   "Е": 400 очков
   "С": 300 очков
   Итого за новые буквы: 700 очков
   Бонус (+1/3): 350 очков
   Всего получено: 1050 очков
```

## ⚠️ Примечания

- Бот работает в групповых чатах и личных сообщениях
- Каждый чат имеет свою независимую игру
- **Ведущий НЕ участвует в игре** - только загадывает слово
- Первым ходит тот, кто первый предложит букву в чате
- При правильном ответе игрок продолжает ходить, при ошибке - ход переходит следующему
- При повторной попытке буквы ход не передаётся
- Буквы регистронезависимы (П = п)
- **Нормализация букв**: Й считается равной И, Ё равна Е, Ъ равна Ь
- **Очки при /try**: только за угаданные буквы (100-1000, кратно 100) × количество вхождений. Без бонуса
- **Очки при /guess**: базовые очки за неугаданные буквы + **всегда бонус 1/3**
- Можно угадывать одно слово из фразы командой `/guess` - очки начисляются только за буквы угаданного слова
- В конце игры показывается детальная статистика очков за каждую букву
- Очки сбрасываются при начале новой игры или загадывании нового слова
- Угадывание слова доступно только в свой ход
