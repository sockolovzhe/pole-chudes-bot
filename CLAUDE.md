# pole-chudes-bot

Телеграм-бот «Поле чудес» для групповых чатов: ведущий загадывает слово (сам или через AI-загадку по реальным праздникам дня), игроки по очереди угадывают буквы и слово, очки и статистика хранятся в MongoDB.

## Команды разработки

- `npm start` — запуск бота (нужен MongoDB и `.env`)
- `npm run dev` — запуск с nodemon
- `npm test` — автотесты (`node --test test/`), сеть и БД не требуются

Локальный запуск бота падает с ошибкой 409: в `.env` тот же BOT_TOKEN, что на проде. Для локальной отладки нужен отдельный тестовый бот от BotFather. Логику проверяем тестами и симуляциями с фейковым `ctx`, а не запуском.

## Архитектура (кратко)

- Состояние игр — **в памяти** (`games.js`: Map чат → `GameState`), при рестарте бота теряется, включая отложенные старты (`setTimeout`). БД хранит только результаты и статистику.
- `handlers/` регистрируются в `handlers/index.js`; `textInput.js` подключается **последним** — он перехватывает ответы на ForceReply-подсказки (`pending.js`) и превращает их в аргументы команд (типы: try, guess, word, question, imagetheme, schedule).
- Загадывание слова — пошаговый диалог: слово → вопрос → тема картинки → время старта (ЧЧ:ММ или «сейчас»). Черновик живёт в `game.pendingRiddle` (флаг `custom` отличает своё слово от сгенерированного).
- Генерация загадок: `riddleGenerator.js` (Groq, модель `openai/gpt-oss-120b`) + `holidays.js` (реальные праздники дня с calend.ru, кэш на сутки по Екатеринбургу). Валидатор не пропускает ответ в тексте загадки; при утечке текст переписывается через AI, крайний случай — маскировка `███`.
- Всё время — по Екатеринбургу (UTC+5, без летнего времени): `time.js`, зона захардкожена.
- Загаданное слово уходит ведущему в личку (`notify.js`); фолбэк — спойлер в чате, если ведущий не открывал диалог с ботом.

## Внешние сервисы и лимиты

- **Groq** (`GROQ_API_KEY`): бесплатный тариф ~8k токенов/мин и 100k/день на модель; промпт с описаниями праздников «дорогой» (~3–4k токенов на попытку). При rate limit генератор ждёт 12 с и повторяет. `llama-3.3-70b` отключена у Groq с 16.08.2026 — не откатывать на неё.
- **calend.ru**: официального API нет, парсим HTML (`holidays.js`); страница даты содержит и соседние дни — парсер привязывает праздники к маркерам дат. При недоступности сайта генерация работает на знаниях модели.
- **Pollinations.ai**: картинки, бесплатно и без ключа, понимает русские темы; генерация до 90 с, всегда в фоне.

## Деплой

GitHub-пуш сломан (ключ удалён из аккаунта sockolovzhe), поэтому деплой через git bundle:

```bash
git bundle create /tmp/deploy.bundle master
scp /tmp/deploy.bundle vps:/tmp/deploy.bundle   # ssh-алиас vps, порт 2222
ssh vps 'cd ~/pole-chudes-bot && git pull /tmp/deploy.bundle master \
  && docker compose -f docker-compose.production.yml up -d --build bot'
ssh vps 'docker logs pole-chudes-bot-prod --tail 5'   # ждём «Бот запущен!»
```

Секреты на сервере — в `~/pole-chudes-bot/.env` (не в git); новые переменные добавлять туда отдельно. `SERVER_IP` из `.env.production` устарел — ходить только по алиасу `vps`.

## Соглашения

- Комментарии и сообщения бота — на русском; общение с пользователем — на русском.
- Ответы бота начинаются с эмодзи-маркера (✅/❌/⏰/🎩 и т.п.) — сохранять стиль.
- Новые команды добавлять в `BOT_COMMANDS` (`index.js`) только если они нужны в меню Telegram; `generate` и `word` из меню убраны сознательно (кнопки после `/newgame`).
